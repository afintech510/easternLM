## Screened Topsoil Use Cases

Screened topsoil is a strong default for grading, leveling, and general lawn preparation.

## Compost Blend Use Cases

Compost blend topsoil is better for new planting zones and areas that need nutrient support.

## Decide By Project Goal

- Use screened topsoil for structure and grade control.
- Use compost blend where soil health is the priority.

## Quantity Planning

Measure each zone separately and run a calculator estimate for each depth target. This prevents over-ordering enriched soil in areas that only need base correction.

## Pairing Suggestions

- Topsoil + straw for seed protection.
- Compost blend + mulch for moisture retention.
